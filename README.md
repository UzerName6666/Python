# Запуск проекта

## Требования для запуска:
1) Python 3.12.8 или выше
2) aiohttp
3) VS Code
4) Расширения для VS Code для работы с Python

## Как запустить

1) Клонирование репозитория
    git clone https://github.com/UzerName6666/Python.git

2) Открыть проект через VS Code и запустить test.py

## Возможные ошибки

    ModuleNotFoundError: No module named 'aiohttp'

Решение: Установить aiohttp или сменить версию Python

    python.exe pip install aiohttp
