## Возможные ошибки

### Отсутствует библиотека 'aiohttp'

    ModuleNotFoundError: No module named 'aiohttp'

Решение: Установить aiohttp или сменить версию Python

    python.exe pip install aiohttp

### Ошибки при проведении тестирования

    Не пройден: "Error: DNS Error"

Возможно отсутствует подключение к сети. В случае возникновения такой ошибки сначала требуется проверить подключение к сети и настройки фаервола
